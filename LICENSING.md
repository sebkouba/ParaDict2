## Why This Approach?

I'm an individual developer sharing this project with the community. I've chosen GPLv3 with dual-licensing for a few reasons:

1. **I want the code to be useful.** Anyone can use, study, and modify it for personal or open-source projects.

2. **I want to prevent exploitation.** GPLv3's copyleft provisions mean that companies can't just take this work, build proprietary products on top of it, and give nothing back.

3. **I want to leave options open.** I'm still figuring out the right balance. If the community feedback suggests a different approach would be better, I'm open to relaxing the license in the future (e.g., moving to MIT or Apache). It's much easier to go from restrictive to permissive than the other way around.

4. **I want to sustain development.** Commercial licensing provides a path for businesses to use this software in ways GPLv3 wouldn't allow, while supporting continued development.
